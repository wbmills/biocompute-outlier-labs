Watching the neurons match a query

One trial of the reservoir experiment, step by step: four keys, one query, and the neurons voting for the best match. Every number on this page comes from a real run (seed 42, 40 tries per trial).

3. Inside four neurons, 40 tries each

Each dot is a spike. Each row is one try. Time runs left to right from the key pulse. We count only the spikes in the shaded 2 ms after the query pulse.

Same trial, four example electrodes, one for each combination of key bit and query bit.

4. The neurons behave like a leaky AND gate

Across all 8 trials (10,240 electrode-tries): how often a neuron spiked in the readout window, by which of its two bits were on.

A perfect AND gate would be 0% / 0% / 0% / 100%. “Both bits” fires about twice as often as “query bit only”: that gap is the multiplication the neurons do. The rest is noise. (Key-only is low because we only count spikes after the query pulse.)
